## 5. データ品質と解釈上の制約

| 項目 | 件数（ユニーク動画） |
| --- | --- |
| 再生回数欠損 | 0 |
| 再生回数0 | 3 |
| 高評価数欠損 | 39 |
| コメント数欠損 | 65 |

- 欠損をゼロに置換しません。率は再生数>0かつ分子が取得できた動画で算出します。率の有効本数はanalysis.jsonに保存しています。
- 平均率は動画別率の単純平均。合計ベース率は有効動画の分子合計÷再生合計で、別指標です。
- 視聴者属性、予約、来訪、消費額、コメント本文は取得していません。コメントの多さを好意・需要とは断定できません。
- 検索順位、投稿後経過時間、動画長、Shorts、チャンネル規模を調整した因果分析ではありません。
- 検索カテゴリを19に限定しており、他カテゴリの川越動画を網羅しません。
- 元資料とは取得時点・地域設定・辞書が異なり、過去からの増減を示す比較には使用しません。
- 全動画の目視・音声確認やUGC／公式投稿分類は未完了。施策は探索的仮説として扱います。
