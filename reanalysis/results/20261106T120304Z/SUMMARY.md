# 川越インバウンド施策：新規データによる再分析

調査日：2026年11月6日。YouTube Data APIで新しく取得した1,305本を分析しました。前回の数値や結論は引き継いでいません。

## 提案の要点

**情報発信の基本は「東京からの日帰りで、何を体験・飲食できるか」を具体的に見せることです。** 中国語向けは日帰りルートと食・街並み、英語向けは日帰りと食に加えて制作体験、韓国語向けはカフェ・日帰り・アクセスを優先して小規模に検証することを提案します。

これは来訪や売上への効果を確認した結論ではなく、動画メタデータと反応から導いた発信内容の仮説です。

検索集合の延べ件数は1,632本ですが、同じ動画が複数言語で見つかるため、ユニーク動画数は1,305本です。中国語設定428本のうち348本がタイトル文字種では日本語候補でした。言語設定だけを使った比較では混入の影響が大きくなります。

参考集合は実際の動画言語を目視・音声で確認した集合ではありません。文字種ルールの誤分類、公式・企業投稿の混入、川越以外も扱う周遊動画を含む可能性があります。以下のテーマ比較はすべてこの参考集合による探索的な結果です。

## 2. 言語別の判断と提案

### 中国語向け：着物単独より、日帰りルート・食・街並みを先に検証

| テーマ | 該当本数 | 該当動画の再生中央値 | 非該当動画の再生中央値 |
| --- | ---: | ---: | ---: |
| 日帰り | 18 | 30,371.5回 | 2,745回 |
| 食・グルメ | 24 | 22,243.5回 | 2,745回 |
| 江戸・歴史 | 27 | 25,319回 | 1,914.5回 |
| 神社 | 26 | 19,325回 | 2,755回 |
| 着物 | 3 | 11,973回 | 10,406.5回 |

元提案の「着物×神社×グルメ」のうち、今回の集合で着物は3本のみでした。優先テーマとする根拠は弱いため、着物は選択できる追加体験として位置づけます。「駅から街並み・神社・食を回る日帰りコース」を中心に、移動時間・費用・立ち寄り先を明示した発信を試します。

ただし、中国語の参考集合は43本、2025年11月6日以降の投稿は12本です。中国語圏全体の需要を代表するとは言えず、追加収集・目視確認を優先します。

### 英語向け：日帰り・食は維持し、制作体験を独立して試す

日帰り133本の再生中央値は1,637回、非該当は614回。食・グルメ108本は1,466.5回、非該当は661回。サツマイモ42本は1,316.5回、非該当は817回でした。日帰りと食を組み合わせる方向は、今回の記述統計とも整合します。

一方、英語参考集合の平均再生は45,058.5回ですが、最大の1本を除くと6,396.4回です。最大動画は[川越での箸づくり体験](https://www.youtube.com/watch?v=DgIBFrhO-D8)で、14,852,627回、集合内再生の85.8%を占めます。説明文・タグに川越の店舗・体験が明記されていることを確認しました。異常値として削除せず、除外時の数値も併記しています。

この1本から「制作体験全般に需要がある」とは断定できません。ただし、工程・完成品・持ち帰れる記念品・英語での対応を見せる制作体験動画は、新たに試す価値があります。日帰り案内と体験の短い動画を別々に試し、予約ページへの移動を測ります。

### 韓国語向け：「江戸・歴史」を主軸と決めず、カフェと日帰りの実用情報を検証

| テーマ | 該当本数 | 該当動画の再生中央値 | 非該当動画の再生中央値 |
| --- | ---: | ---: | ---: |
| カフェ | 22 | 1,578回 | 525.5回 |
| 日帰り | 41 | 874回 | 526回 |
| 交通・アクセス | 22 | 875.5回 | 528.5回 |
| サツマイモ | 36 | 777.5回 | 537回 |
| 江戸・歴史 | 114 | 555回 | 559.5回 |

江戸・歴史の該当動画は多い一方、中央値では非該当を上回りません。「江戸への関心が特に高い」とする前回の表現は、今回の結果からは維持できません。

提案は、カフェ・サツマイモ・神社をつなぐ半日／日帰りコースです。東京からの具体的な乗車駅・乗換・所要時間と合わせて紹介します。レトロな街並みは背景として使い、主な訴求を変えた動画同士で比較します。

カフェの該当数は22本であり、テーマだけによる効果は分離できていません。高いコメント率を購買意欲と見なすこともしません。

### 日本語：比較対象として食・日帰りの訴求を参考にする

食・グルメ69本の再生中央値は11,984回、非該当は1,181回。日帰り18本は17,319.5回、非該当は1,876.5回でした。国内向けで使われている具体的なルートや飲食紹介の構成は、外国語動画の企画を考える参考になります。ただし日本語動画の反応を、そのまま訪日客の関心に置き換えません。

## 3. 前回の結論との違い

| 元の方向性 | 今回の判断 |
| --- | --- |
| 中国語：着物×神社×グルメ | 日帰りルート・食・街並みを中心にする。着物は3本のため追加検証 |
| 英語：日帰り×サツマイモ | 方向は維持。突出した制作体験の動画を独立した仮説として追加 |
| 韓国語：江戸・歴史×グルメ | 江戸・歴史の優位性は確認できず。カフェ・日帰り・アクセスを先に検証 |
| 英語の高評価率・韓国語のコメント率が高い | 絞り込み方と平均／合計ベースの違いで順位が変わるため、市場の魅力度の順位には使わない |

時点・検索条件・辞書が異なるため、この差を「観光客の嗜好が変化した証拠」とは解釈しません。

## 4. 実行と効果検証

以下は新たな実施案であり、実測結果ではありません。

1. **最初の1〜2週：** 中国語の追加確認と、各言語の候補動画・事業者情報の確認を行います。旅程に記載する交通・価格・予約条件は公開前に確認します。
2. **次の2週：** 言語ごとに主な訴求が異なる動画を2案程度試します。投稿形式・長さ・配信条件を可能な範囲でそろえます。
3. **約1か月後：** 再生数だけでなく、リンクのクリック率、予約・問い合わせ率、実際の来店・利用を評価します。広告を使う場合は費用も含めて比較します。

言語別・動画別の専用リンクや識別コードで来訪導線を追います。予約情報を集められない場合は、来訪効果を測定できたとは表現しません。必要なサンプル数や達成目標は、配信予算・現在の実績を基に設定します。

## 5. 分析として確認できた範囲

- データ収集、動画ID重複排除、検索集合の重複、欠損とゼロの区別、テーマ別再集計を実施しました。
- 全動画の視聴による言語・川越関連性・UGC区分の確定、チャンネル規模や形式を調整した効果推定は行っていません。
- 率や再生数は動画の観測値です。観光需要・来訪数・売上を直接測った結果ではありません。
