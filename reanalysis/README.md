## APIキーの設定

このフォルダの `.env.example` をコピーして `.env` を作成し、`replace_with_your_key` の部分をYouTube Data API v3のAPIキーに置き換えて保存してください。キーをチャットに貼る必要はありません。

環境変数 `YOUTUBE_API_KEY` も使用できます。ただし、別のPowerShellで設定したプロセス環境変数は、起動済みのCodexに引き継がれない場合があります。ローカルの `.env` ファイルが確実です。

`.env` はGit管理対象外です。このフォルダを共有する場合もキーを含めないでください。

## 収集

```powershell
python collect.py --pages 10
```

4言語×最大10ページで、検索は最大40回、各検索集合は最大500件です。最終ページで終了し、重複動画を除いて統計を一括取得します。実際の取得数は検索結果に依存します。

元の研究と同じ旅行・イベントカテゴリ（19）を対象にします。地域条件は4言語で統一して指定なしとします。対象公開期間は制限なしで、検索順は関連度です。したがって全UGCの無作為標本でも、直近1年間の動向分析でもありません。

## 記録するデータ

`runs/取得日時/` にAPI応答、検索集合ごとの動画ID、動画単位データ、条件・取得日時・ハッシュを保存します。欠損統計はゼロで置換しません。取得に失敗した実行は `incomplete` と記録します。

## 再分析方針

1. 検索集合と実際の動画言語を区別し、混入・言語間重複を確認。
2. 川越観光との関連性、公式広報・事業者投稿等を確認。検索結果すべてを自動的にUGCと見なさない。
3. 表記ゆれ・繁体字／簡体字・英語の大小文字を考慮した辞書を事前に固定。
4. 動画本数、平均・中央値、動画別反応率の平均、合計ベースの反応率を分けて集計。
5. 再生0・統計欠損を明示し、少数サンプル、突出した動画、投稿時期、チャンネル集中の影響を点検。
6. 元の結論を前提にせず、新しい観測結果から言語別の施策を検討。

元資料の2026年8月時点の結果とは別の時点・一部異なる条件の調査です。時系列変化を厳密に比較する設計ではありません。
