# UGC分析による川越市のインバウンド施策提案

YouTube Data API（v3）を活用し、4言語（日本・中国・英語・韓国）のUGC（ユーザー生成コンテンツ）データを取得・分析。各言語話者の関心キーワードやエンゲージメント特性を特定し、ターゲット別インバウンド施策を提案したプロジェクトです。

## リポジトリの構成
- `UGC分析による川越市のインバウンド施策提案.pdf` : 最終提案書（PDF）
- `川越Youtube分析(日本語).ipynb` : 日本語データ分析コード
- `川越Youtube分析(中国語).ipynb` : 中国語データ分析コード
- `川越Youtube分析(英語).ipynb` : 英語データ分析コード
- `川越Youtube分析(韓国語).ipynb` : 韓国語データ分析コード

### 3. データ分析からのインサイト
* **日本語圏**: 食べ歩き・東京・グルメを含む動画の再生数や高評価の数が高かったことから日本人からは東京近郊のグルメ目当ての観光スポットとしての需要が高いと考えられる。
* **中国語圏**: グルメを表す語の再生数が高かった。また、着物や神社などの日本の伝統的な文化にも多く関心が寄せられた。
* **英語圏**: 再生回数は控えめだが高評価率が最も高い。サツマイモやスイーツ、食べ歩きなどのグルメの要素を持つものや東京、日帰りなどのアクセス・周遊性といった要素も再生数が高い傾向がみられた。
* **韓国語圏**: コメント率が4言語中最高。サツマイモやグルメなどの食に加えて江戸に対する関心も高いと分かった。
##  提案した施策
- **中国語圏**: 着物レンタル×神社巡り×グルメのモデルルートのPR
- **英語圏**: 東京発・1時間で行ける日帰り伝統体験＆サツマイモスイーツに重点を置いた
- **韓国語圏**: 「一番近い江戸時代」をコンセプトとした歴史・レトロ動画・グルメを融合させた動画コンテンツを発信
